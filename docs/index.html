Find it, fix it, prove it. Repeat until green.

Kane's verdicts, evidence and measured values go to Claude Code. Claude edits files only. Kane re-runs whatever failed; anything still red goes back for another round, up to three. When everything passes, a full regression run checks nothing else broke.

Three ways to run it.

Audit and fix a site you serve locally. Audit every client from a text file, without ever sending a fake lead. Or add the GitHub Action, and every pull request gets a comment with its leak score.

# find and fix adleak fix http://localhost:3000 \ --dir ./public --budget 100 \ --expect google_ads,ga4,meta # read-only audit of client sites adleak audit clients.txt --out leaks # in CI uses: muhamed-kanapiya/adleak@main
