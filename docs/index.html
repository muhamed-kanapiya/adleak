The problem

None of these break the build.
They just quietly waste money.

Button goes nowhere

CTA anchor typo #lead-from. Paid click → bounce.

Lead form fails

POST /api/leads → 404. Lost at the last step.

UTMs never reach the CRM

utm-source vs utm_source. No attribution.

Pixel fires twice

Meta Lead ×2 per lead. The algorithm learns from fake conversions.

Popup hides the CTA

Fine on desktop, 72% overlay on phones where most paid traffic lives.

Slow first screen

Synchronous chat widget → LCP 3.2 s. Visitors leave before the offer.

How it works

A closed loop. The agent can't grade itself.

Kane CLI runs every check in real Chrome and returns verdicts with evidence. Claude Code gets the failures and patches the site. Only Kane can turn a check green, then a full regression pass makes sure nothing else broke.

Run it

CLI, agency mode, GitHub Action.

Audit any URL, auto-fix a site you serve locally, audit every client from one file (no fake leads are sent), or block PRs that break tracking with a sticky leak-score comment.

# audit + auto-fix
adleak fix http://localhost:3000 --dir ./public \
  --budget 100 --expect google_ads,ga4,meta

# read-only audit of a live site
adleak audit https://client.com --no-submit

# agency mode: one URL per line
adleak audit clients.txt --out leaks
